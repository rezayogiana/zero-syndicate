# Deploy ZERO SYNDICATE V4.0
1. Backup repo lama.
2. Upload file dari ZIP ini ke repo GitHub `zero-syndicate`.
3. Commit ke branch `main`.
4. Cloudflare Pages akan build folder `public`.
5. Render akan deploy backend dari folder `backend`.
6. Cek `https://zero-syndicate.onrender.com/api/health` dan pastikan version = 4.0.
